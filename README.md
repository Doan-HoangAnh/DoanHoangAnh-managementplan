# Student Internship Management System

## Project Overview

This repository contains a sample project management plan for a Student Internship Management System.

The project applies Agile and Kanban concepts to manage software requirements and User Stories.

## Project Objectives

The proposed system helps:

- Students browse internship opportunities.
- Students submit weekly internship reports.
- Supervisors review reports and provide feedback.

## Project Management Tool

GitHub Projects was selected to manage the project because it integrates directly with GitHub Issues and supports Kanban boards.

## Kanban Workflow

The project uses three statuses:

- Todo
- In Progress
- Done

## Project Requirements

The project contains:

- 3 Functional Requirements
- 2 Non-Functional Requirements
- 3 User Stories
- Acceptance Criteria for each User Story
- 3 GitHub Issues
- 1 GitHub Project board
